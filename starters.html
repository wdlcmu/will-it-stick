Six small starts

Shapes to start from. Not your text.

Each check hands back six shapes.

They are starts, not a rewrite.

You pick what fits. You write the rest.

Each sample below came from a real run.

1. The proverb

Your point in one short line.

A line a friend can repeat.

If it is long, it is not this shape.

From a real run

“Fix it free, save money.”

From the repair night run. See Examples.

2. The gap opener

A first line that withholds one fact.

It makes a question in the mind.

The next line pays the question off.

From a real run

“What happens on first Saturdays?”

From the repair night run. See Examples.

3. The story: a hard test

A small plot of three or four lines.

A person hits a block. They act. It ends.

Use facts from your text. Add none.

From a real run

“The project faced many problems. We worked hard to fix them. Still, we need help to stay on track.”

From the work note run. See Examples.

4. The story: a bond

A small plot of three or four lines.

Two people meet. A bond forms.

Use facts from your text. Add none.

From a real run

“We fix things. You bring a lamp. We fix it free. You get coffee.”

From the repair night run. See Examples.

5. The story: a new spark

A small plot of three or four lines.

A spark hits. A new thought forms.

Use facts from your text. Add none.

From a real run

“We make new plans. We use best practices. We grow.”

From the weak memo run. Flat words make flat tales.

6. Concrete swaps

Vague words hide the point.

A swap trades them for a scene.

You can see a scene. You can keep it.

From a real run

“cross-functional synergies” → “teams work together”

From the weak memo run. The swap is plainer, not grander.

What you do with them

Pick one shape. Start from it.

Write the rest in your own words.

We don't write it for you.

You stay the author.
